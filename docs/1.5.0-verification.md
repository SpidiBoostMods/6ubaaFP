# 6ubaaFP 1.5.0 — local verification

Prepared for Fabric / Minecraft 1.21.4 / Java 21. GitHub publication is gated by the release workflow's Windows/macOS/Linux tests. Not installed into the user's Prism instance.

## Changes

- Esc stops inventory scanning and full-route navigation, retaining/opening the partial result. FP scanning is not cancelled by this shortcut.
- Every comma-separated inventory requirement is mandatory. Counts are summed over all upper server slots, excluding the viewer inventory. Exact / mathematical comparisons always exclude zero.
- Known vanilla IDs accept shorthand, with canonical minecraft:id suggestions. Names remain exact, formatting-free and case-insensitive. Optional numerical route prefixes accept commas, whitespace and ranges; sorted/deduplicated routes stay within 1–56. A single number selects that grief only.
- The HUD defaults to above the action bar, can be dragged through ChatScreen, and persists GUI-scaled coordinates atomically in config/6ubaafp-hud.properties. Bounds clamp after resizing/GUI-scale changes.
- Manual unban invalidates its associated FP ban; ReallyWorld unban does not. Other eligible FP bans of the same nickname remain eligible. Late manual unbans retract provisional findings without corrupting the next owner.
- Inventory diagnostics record actual counts and requirement bounds. Existing updater, result guards, root paths, global deduplication and chat clearing remain intact.
