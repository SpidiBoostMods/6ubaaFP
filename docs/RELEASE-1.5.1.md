6ubaaFP 1.5.1 · Fabric 1.21.4 · SpidiBoost

[~] Автообновление — Prism обнаруживается на диске даже при закрытом лаунчере; после установки запускается именно текущий инстанс.
[~] update on — проверка при запуске Minecraft и каждом входе, сохранение результатов, отсчёт, выход, установка и повторный запуск.
[~] update off — новый JAR скачивается в mods без перезапуска; независимый помощник после выхода резервирует и удаляет старую версию.
[+] Помощь — если безопасное обновление недоступно, при каждом входе показывается красивая кликабельная ссылка vk.ru/paveljaparov.
[~] Повторные проверки — скачанный JAR больше не блокирует GitHub; проверенный файл используется повторно, более новый релиз заменяет подготовленный.
[~] Надёжность — защита от чужих JAR, SHA-256, откат, резервные копии и понятные логи без данных аккаунта; старые встроенные обновляторы не перехватывают управление.

Для применения исправления текущей 1.4.1 требуется один полный запуск с новым JAR. Публикация на GitHub не меняет код уже работающего Minecraft.
