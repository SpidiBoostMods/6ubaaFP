# Локальная 1.3.0 — 9 октября 2026

Автор: SpidiBoost. Fabric 1.21.4, Java 21. GitHub не опубликован; пользовательская Prism-инстанция не изменялась.

## Изменения

- `Ошибка: Игрок не найден.` (включая время и форматирование) и уход из TAB пропускают недоступный инвентарь.
- Молчание сервера/незагруженное окно повторяет `/invsee` тому же владельцу без лимита попыток. Интервал 1,5–5 с, после повторов 2 с тишины для удаления дублирующихся окон. Обычная очередь сохраняет минимальную паузу 5 мс.
- Разрыв соединения в момент отправки запроса не выпускает исключение из очереди; частичный результат сохраняется.
- При стопе/кике/закрытии файл открывается; отдельный JDK-помощник открывает атомарно сохранённый файл даже после жёсткого завершения игрового JVM. Нужен рабочий Java и доступное приложение для TXT.
- Собственное оформление: медь → шампань → нефрит, мягкая анимация, компактная адаптивная панель, центральные титры и нижнее уведомление. Чужие сообщения и цвета не изменяются.
- `/6ubaafp update [on|off]`: статус версий/проверки и настройка автоперезапуска (по умолчанию включён). Загрузка остаётся включённой при `off`, установка безопасно выполняется после выхода JVM. Настройка учитывается единственным координатором семейства, включая прежние версии с общим ObjectShare-ключом.
- Корень `/6ubaa` удалён. В сопутствующей локальной SpidiCard 1.5.1 удалён `/spidicart`; `/spidicard` сохранён.

## Выполненные проверки

- 6ubaaFP: `check build`, 120 JUnit-тестов, 0 ошибок/пропусков. Включают 1000 инвентарей, поздние/повторные окна, полную загрузку пустого контейнера, исключённые слоты проверяющего, точные имена/ID, права, ошибки записи, обрыв отправки, бесконечные повторы и сохранение остановленного full.
- SpidiCard: `check build`, 104 JUnit-теста, 0 ошибок/пропусков; нативный `runVerification -PqaMenu` проверил отсутствие алиаса, прежнюю команду, повторное открытие результатов и обычную проверку игроков.
- Нативный Fabric 1.21.4/macOS: настоящий локальный сервер отправляет `Player`, полные пакеты инвентаря, `Ошибка: Игрок не найден.`, удаляет игрока из TAB и пропускает первые два запроса. Третья попытка открывается; следующий игрок проверяется; результат и запуск текстового редактора подтверждены.
- Нативный `/stop` и кик: проверка остановлена, уже найденный ник остался в файле, помощник подтвердил открытие.
- Нативный `runVerification -PfpNative -PfpCrash`: отдельный тестовый JVM завершён через `Runtime.halt(0)` при **активной** проверке, после сохранённого совпадения и READY от ещё живого помощника. До завершения файла-подтверждения не было; после завершения появился `viewer-opened.txt`, частичный TXT сохранился. Обработчик остановки не выполнялся.
- Отрендерены настоящий `Player`, новая панель и цветной текст; скриншоты просмотрены. Проверены Unicode, сохранение чужого цвета, 6 форм inv/invsee, update on/off и красные офлайн-аккаунты без TAB-фильтра.
- Проверены метаданные, Java 21, встроенный агент и исключение тестового fixture из выпускаемого JAR.

Проверки проводились в изолированном Minecraft на macOS, не на ReallyWorld и не в пользовательской Prism-инстанции. Новая нативная Windows-проверка и GitHub CI не запускались: публикация запрещена пользователем. Это не утверждение о проверке абсолютно всех возможных серверных/системных сбоев.

Заголовок `Player` не содержит владельца: произвольно позднее окно после любой конечной паузы невозможно безусловно сопоставить по заголовку. Повторы одного владельца и период тишины уменьшают этот риск; тесты покрывают дубли, приходящие во время проверки/периода тишины. Полное отключение компьютера также не позволяет открыть редактор, но уже сохранённый результат остаётся на диске.

Установка вручную: заменить старые 6ubaaFP и SpidiCard соответствующими новыми JAR; не оставлять две версии одного мода в `mods`.
