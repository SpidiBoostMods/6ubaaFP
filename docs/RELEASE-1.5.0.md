# 6ubaaFP 1.5.0 · Fabric 1.21.4

Автор: SpidiBoost.

[+] Esc — мгновенная остановка inv/invsee с сохранением и открытием частичного результата, включая режим full
[+] Панель прогресса — перетаскивание левой кнопкой через открытый чат; положение сохраняется в config/6ubaafp-hud.properties, по умолчанию панель над нижней строкой прогресса
[+] Короткие ID — compass работает как minecraft:compass; TAB предлагает полный ID, в том числе после запятых и списка грифов
[+] Количество — суффиксы (6), (=6), (>=6), (>6), (<3), (<=3); суммируются все серверные слоты, ноль всегда исключён
[+] Маршрут inv full — точные номера и диапазоны через запятую или пробел, по возрастанию и без дублей; без списка сохраняется обход всех 56 грифов

[~] Фильтр предметов — все перечисленные предметы обязательны (И вместо ИЛИ); пробелы около запятых необязательны
[~] История FP — вручную снятый бан исключается; разбан от ReallyWorld учитывается только в связанной FP/Funpay/Playerok-записи, независимо от ручных разбанов других записей этого же ника
[~] Запоздалые разбаны — отзывают ранее найденное совпадение без подмены владельца следующей истории
[~] Диагностика — журнал содержит фактические количества предметов и границы каждого условия

Пример: /6ubaafp inv full 1,4,2-5 compass,obsidian(6) — грифы 1–5, обязательны компас и ровно 6 обсидиана.

Локально пройдены 143 автотеста и две изолированные нативные проверки Minecraft 1.21.4 на macOS: настоящие окна Player, ItemStack, TAB-подсказки, клавиатура/чат, сохранение и чат-пакеты с ручными/автоматическими разбанами. Публикация разрешается только после успешного CI Windows/macOS/Linux. Проверка на живом ReallyWorld не проводилась.

Приложены JAR, архив исходного проекта и SHA-256 манифест для существующего автообновления. Автоперезапуск регулируется /6ubaafp update on/off; off не отключает загрузку обновлений. Другие моды этим выпуском не обновляются. Агент не устанавливает JAR в Prism.
