## Границы проверки

Не выполнены: реальный прогон живого ReallyWorld, полный серверный обход 1–56 новым модом и запуск на настоящей Windows. JAR использует переносимые API Minecraft/Java, а открытие файла — платформенный механизм самого Minecraft; это не выдаётся за доказательство работы Windows UI.

Фильтр выбран консервативно: жёлтый аккаунт должен также быть в TAB текущего грифа. Запрос был «только онлайн на грифе», поэтому один цвет без локального присутствия недостаточен.

Для живой проверки: полный перезапуск клиента, `/6ubaafp start` на грифе с доступными dupeip/hist; сверить результат и `sixubaafp/<сессия>/debug.log`, затем запустить full. Другие автоматические обходы одновременно не включать.
