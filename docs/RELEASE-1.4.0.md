# 6ubaaFP 1.4.0 · Fabric 1.21.4

Автор: SpidiBoost.

- Убраны повторные `/hist` из-за несовпадения серверного «Лимит» и числа записей. Поддерживается `[Горит]`.
- Ник проверяется один раз на весь `start` или маршрут `full`, без учёта регистра. Пересекающиеся группы используют кэш запуска.
- Очередь остаётся последовательной, с минимальной паузой 5 мс после ответа. Пустые истории пропускаются без отдельного кулдауна; поздние записи сохраняют владельца.
- Текущий игровой аккаунт исключён из `/dupeip` и `/hist`, включая смену аккаунта после запуска Minecraft.
- Каждые 20 историй очищается отображаемый чат, без удаления очереди и найденных ников.
- Красные FP-аккаунты записываются с онлайн-твинками: `nick (На сервере: twin1, twin2)`. TAB используется для этой подписи, не для ограничения историй офлайн-аккаунтов.
- Полностью отсутствующие ответы сохраняются в журнале без повторного запроса и повторного обхода грифа. «Игрок не найден» пропускается сразу.

Также включены ранее локальные улучшения 1.3.0: устойчивые повторы `/invsee`, сохранение и открытие частичного TXT при остановке/кике/аварийном выходе, новое оформление, `/6ubaafp update on/off`. При `off` обновление по-прежнему загружается, но автоматический перезапуск отключён. Алиас `/6ubaa` удалён; основной корень `/6ubaafp` сохранён.

Проверки: автотесты очередей/маршрута/инвентарей/обновлений, воспроизведение 572 ответов реального журнала и изолированный Minecraft с настоящими чат-пакетами. Публикация доступна только после успешных тестов Windows, macOS и Linux.

Для ручной установки замените старый JAR новой версией, не оставляя две версии 6ubaaFP одновременно. Существующее GitHub-автообновление использует прилагаемый SHA-256 манифест. SpidiCard этим выпуском не обновляется.
